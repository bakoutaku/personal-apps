# 个人应用

简体中文 · [日本語](README.ja.md) · [English](README.en.md)

这里收录我用 AI 辅助开发的个人应用。各项目有独立目录和三语说明，应用界面目前主要使用中文。

| 项目 | 可以做什么 | 当前状态 |
| --- | --- | --- |
| [AI Usage Dashboard](ai-usage-dashboard/) | 查看 Codex 和 Claude Code 的本机用量、活动历史和已记录的 Codex 额度 | macOS 源码预览，可先用模拟数据体验 |
| [Claude Companion](claude-companion/) | 在 macOS 桌面显示 Claude 的工作状态、授权提醒和回复结束提示 | macOS 源码预览，有内置演示 |
| [Wardrobe](wardrobe/) | 整理衣物、照片、穿搭和购买记录，也可在本机生成分类建议 | 本机试用版，附虚构数据演示 |
| **MediaLibrary** | 索引和整理本机图片收藏 | 开发中 |

各项目的 README 包含环境要求、运行步骤和已知限制。Dashboard 和 Companion 的 README 也记录了开发过程中使用过的角色素材出处。
