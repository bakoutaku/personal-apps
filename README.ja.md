# 個人アプリ

[English](README.en.md) · [简体中文](README.md) · 日本語

生成AIを活用して制作した個人アプリです。Dashboard、Wardrobe、Claude Companion の初期表示は簡体字中国語です。Web アプリ上部またはデスクトップペットのメニューから日本語や英語に切り替えられます。

- [AI Usage Dashboard](ai-usage-dashboard/README.ja.md) · CodexとClaude Codeの利用状況を表示するmacOS向けソース版プレビュー。
- [Wardrobe](wardrobe/README.ja.md) · 衣類、コーディネート、購入記録を管理するローカル試用版。
- [Claude Companion](claude-companion/README.ja.md) · Claude向けのmacOSデスクトップマスコット。ソース版プレビュー。
- **MediaLibrary** · ローカル画像ライブラリーの試作アプリ。開発中。
