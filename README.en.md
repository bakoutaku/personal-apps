# Personal Apps

English · [简体中文](README.md) · [日本語](README.ja.md)

Personal apps developed with AI assistance. Dashboard, Wardrobe, and Claude Companion default to Simplified Chinese. Choose Japanese or English from the selector in each web app or the companion menu.

- [AI Usage Dashboard](ai-usage-dashboard/README.en.md) · Local Codex and Claude Code usage dashboard. macOS source preview.
- [Wardrobe](wardrobe/README.en.md) · Local clothing, outfit, and purchase manager. Trial version.
- [Claude Companion](claude-companion/README.en.md) · macOS source preview for an unofficial Claude desktop companion.
- **MediaLibrary** · Local image-library prototype. In development.
